# WhatsApp Chatbot 🤖

A WhatsApp chatbot built using Node.js, Express, MongoDB, and Twilio API.

## 🚀 Features
- Auto-reply using FAQs
- WhatsApp integration (Twilio Sandbox)
- REST API backend
- Real-time webhook handling

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- Twilio API

## 📌 How it works
User sends message → Webhook receives → FAQ match → Reply sent instantly

## 🔧 Setup
1. Clone repo
2. Install dependencies: npm install
3. Add .env file
4. Run server: npm start
